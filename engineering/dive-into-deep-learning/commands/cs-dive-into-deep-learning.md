# /cs:dive-into-deep-learning — Dive into Deep Learning

**Command:** `/cs:dive-into-deep-learning [topic | chNN]`

## When to run

- Studying d2l.ai and want a concept explained or a chapter summarized
- Choosing an architecture, loss, or optimizer for a task (see the cheatsheet)
- Debugging a training run (NaN, flat loss, overfitting, distribution shift)
- Checking whether the book's advice is still current in 2026

## Procedure

1. Read `engineering/dive-into-deep-learning/skills/dive-into-deep-learning/SKILL.md`
   (chapter index + topic index).
2. If the argument is `chNN`, read `chapters/chNN-*.md` directly. Otherwise resolve the topic
   through the Topic Index and read the mapped chapter file(s) — one or two, not all.
3. Answer in your own words; link the d2l.ai chapter for the source. Never reproduce book text.
4. Close with the chapter file's **2026 delta** when relevant.
