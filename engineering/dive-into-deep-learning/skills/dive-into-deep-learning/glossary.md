# Glossary — Dive into Deep Learning

Alphabetized key terms with their chapter. (Compiled synthesis, not book text.)

- **Activation function** — nonlinearity applied per-unit in a hidden layer; ReLU `max(0,x)` is the default, sigmoid/tanh saturate. (ch08)
- **AdaGrad / RMSProp / AdaDelta / Adam / AdamW** — adaptive optimizers; Adam(W) combines momentum + per-coordinate scaling with bias correction; AdamW decouples weight decay. Default: AdamW. (ch15)
- **Anchor box** — predefined box (scale/aspect) at each location that a detector refines. (ch17)
- **Attention** — soft lookup: weighted sum of values with weights = softmax of query–key similarity. (ch14)
- **Backpropagation / BPTT** — chain rule applied in reverse through a graph / through unrolled time; truncated BPTT limits the horizon. (ch08, ch12)
- **BatchNorm / LayerNorm** — normalize activations per batch (BN) or per feature (LN, preferred for sequences). (ch11, ch14)
- **Bellman equation** — $V(s) = R + \gamma \sum P(s'|s,a) V(s')$; the recurrence behind value/policy iteration and Q-learning. (ch20)
- **BERT** — bidirectional transformer encoder pretrained with masked-LM (+NSP); fine-tune for NLP tasks. (ch18–19)
- **Beam search** — keep k best partial hypotheses when decoding sequences. (ch13)
- **Bias (in model)** — intercept term b in affine model. (ch06)
- **BPE (byte-pair encoding)** — subword tokenizer merging frequent char pairs; handles OOV. (ch18)
- **CNN** — convolutional neural network; locality + translation invariance via kernels. (ch10)
- **Cross-entropy loss** — $-\sum y_j \log \hat{y}_j$; the classification loss (= negative log-likelihood). (ch07)
- **Dataset / example / feature / label** — collection of instances; instance = feature vector + target. (ch04)
- **Distribution shift** — train/test mismatch: covariate (P(x)), label (P(y)), concept (P(y|x)). (ch07)
- **DQN** — Deep Q-Network: Q-learning with a neural net + replay buffer + target net. (ch20)
- **Dropout** — randomly zero units at train time (scale survivors by 1/(1−p)); regularization. (ch08)
- **Encoder–decoder (seq2seq)** — RNN encoder compresses source to context; decoder generates target. (ch13)
- **Epoch / minibatch / batch size** — full pass over data / subset used per update / its size (32–256 typical). (ch06)
- **Fashion-MNIST / MNIST** — 28×28 grayscale datasets, 10 classes; the book's running example. (ch07)
- **Feature engineering** — hand-crafted input transforms; replaced by learned representations in DL (end-to-end). (ch04)
- **Fine-tuning** — train a pretrained model on a new task, usually with small lr. (ch17, ch19)
- **Frobenius norm** — ℓ2 norm of a matrix's entries; what weight decay penalizes. (ch05)
- **GAN** — generator vs discriminator minimax game for generative modeling. (ch23)
- **GloVe / word2vec** — static word embeddings from co-occurrence (GloVe: log-count factorization; word2vec: skip-gram/CBOW + negative sampling). (ch18)
- **GPU / VRAM** — accelerator; memory is the binding constraint (model+activations+optimizer states). (ch09, ch16)
- **Gradient descent / SGD / minibatch SGD** — iterative parameter update along −gradient; stochastic = minibatch version. (ch06, ch15)
- **GRU / LSTM** — gated RNNs fixing vanishing gradients via cell state + gates. (ch13)
- **Hidden state** — RNN's memory vector H_t. (ch12)
- **Hyperparameter** — not learned by training (lr, batch size, depth); tuned on validation set. (ch06)
- **IoU / NMS** — intersection-over-union box overlap; non-maximum suppression dedups detections. (ch17)
- **KL divergence** — $D_{KL}(P\|Q) = \sum P \log(P/Q)$, asymmetric, ≥0; ML losses are cross-entropy/KL. (ch25)
- **Kernel (GP)** — covariance function k(x,x') defining smoothness of a GP prior; RBF is standard. (ch21)
- **Learning rate η** — step size in gradient updates; the most important hyperparameter. (ch15)
- **LeNet / AlexNet / VGG / GoogLeNet / ResNet / DenseNet** — CNN lineage; ResNet's residual connections enabled 100+ layers. (ch10–11)
- **Loss function** — scalar measuring model badness; lower is better by convention. (ch04)
- **MLP** — multilayer perceptron: stacked affine layers + activations. (ch08)
- **Momentum** — exponential average of gradients accelerating SGD. (ch15)
- **One-hot encoding** — category as binary vector. (ch07)
- **Overfitting / underfitting** — train-test gap too large / train error too high. (ch06)
- **Perplexity** — $\exp(-\frac1n \sum \log P(x_t|x_{<t}))$; LM quality metric. (ch12)
- **Pooling** — max/avg downsampling over windows; no parameters. (ch10)
- **Positional encoding** — added to embeddings so self-attention knows token order (sinusoidal or learned; modern: RoPE). (ch14)
- **Q-learning** — model-free RL: update $Q(s,a)$ toward $r + \gamma \max_{a'} Q(s',a')$. (ch20)
- **ReLU / LeakyReLU / GELU / SwiGLU** — activation functions. (ch08, ch14)
- **Residual connection** — y = F(x) + x; gradient highway. (ch11, ch14)
- **RNN** — recurrent neural network; hidden state carried across time steps. (ch12)
- **Self-attention** — Q,K,V all from the same sequence; $softmax(QK^\top/\sqrt{d})V$; O(n²). (ch14)
- **Softmax** — $\hat y_i = e^{o_i}/\sum_j e^{o_j}$; logits → probabilities. (ch07)
- **State_dict** — PyTorch's portable model-parameters format. (ch09)
- **Teacher forcing** — feed true previous token during seq2seq training. (ch13)
- **Tensor** — multi-dimensional array (vector/matrix/higher). (ch05)
- **Transformer** — encoder–decoder of attention+FFN blocks with residual+LN. (ch14)
- **Validation / test set** — held-out data for hyperparameter selection / final evaluation; never reuse test. (ch06–07)
- **Vanishing / exploding gradients** — deep/RNN training pathologies; fixed by ReLU, skip connections, init, clipping. (ch08, ch12)
- **ViT** — vision transformer: image patches + encoder-only transformer + [CLS] head. (ch14)
- **Weight decay** — L2 penalty on weights (λ/2‖w‖²); in AdamW it's decoupled. (ch06, ch15)
- **Xavier/He init** — variance-preserving random init (He for ReLU). (ch08)
